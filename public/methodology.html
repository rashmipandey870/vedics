Structured software implementation of traditional Vedic calculation principles

About RashmiSutra

RashmiSutra represents the union of traditional calculation principles (Sutra) structured through modern computational code. Designed as a college-level computer science software project by Rashmi Pandey.

Rashmi = Ray of light / Identity
Sutra = Structured principle or calculation rule
RashmiSutra = Traditional calculation rules implemented through modern software

1. Astrological Methodology

Zodiac System:

Nirayana (Sidereal) Zodiac. Unlike Tropical systems which align with the Vernal Equinox, Nirayana measures longitudes relative to fixed stellar constellations.

Ayanamsha Standard:

Lahiri (Chitrapaksha) Ayanamsha. Calculated using formula: Ayanamsha = 23.85° + (Year - 1950) × 0.01361° (approx. 24.23° for year 2026).

Nakshatra & Pada Division:

360° ecliptic belt ÷ 27 Nakshatras = 13°20' (13.3333°) per Nakshatra. Each Nakshatra is divided into 4 Padas of 3°20' (3.3333°) each, mapping to 108 Navamsha divisions.

Vimshottari Dasha Engine:

Fixed 120-year cycle across 9 Grahas. Starting Mahadasha Lord is determined by Moon Nakshatra. Unelapsed fraction of Moon Nakshatra determines starting balance at birth.

Paya Classification:

Traditional footing metal rule based on Moon House relative to Lagna (House 1,6,11 = Gold; House 2,5,9 = Silver; House 3,7,10 = Copper; House 4,8,12 = Iron).

2. Numerology Methodology

Mulank (Birth Day Number):

Calculated by extracting day of birth (1–31) and reducing digits iteratively until a single digit (1–9) is obtained.

Bhagyank (Life Path Number):

Calculated by summing all digits in complete date string (DD + MM + YYYY) and reducing iteratively to a single digit.

Name Number Mapping:

Chaldean System (A=1, B=2, C=3, D=4, E=5, F=8, G=3, H=5, I=1, J=1, K=2, L=3, M=4, N=5, O=7, P=8, Q=1, R=2, S=3, T=4, U=6, V=6, W=6, X=5, Y=1, Z=7) and Pythagorean System options.
