Section 1

Project Overview & Problem Statement

⚠️

The Problem with Legacy Tools

  • • Opaque Black-Box APIs: Legacy software uses closed binaries with uninspectable formulas.
  • • 15°-25° Secular Drift: Polynomial approximations drift significantly for pre-2000 dates.
  • • No Math Decomposition: Users get final numbers without seeing how calculations were performed.
✨

The JeevanShaili Solution

  • ✓ VSOP87 Ephemeris Integration: High-precision geocentric vectors matching official ephemerides (<0.05°).
  • ✓ 100% Open Math Modals: Interactive '🧮 View Math' modals display step-by-step formulas for viva defense.
  • ✓ Fault-Tolerant Architecture: Automatic session fallback when MongoDB is offline so demo never fails.
Section 2

Full-Stack System Architecture

🖥️

1. Client Layer

Built with HTML5, CSS3 Glassmorphism, and Vanilla JS. Includes an ambient starfield canvas and dynamic 400x400 SVG North Indian Diamond Grid renderer.

⚙️

2. Express Server & Engine

Node.js + Express REST API controllers executing pure JS VSOP87 ephemeris calculations, 120-year Vimshottari timeline matrix, and Yogas pattern recognition.

💾

3. Storage & Geocoding

MongoDB + Mongoose ODM (`ProfileSchema`) with auto in-memory fallback. Integrates 100+ city lookup, OpenStreetMap Nominatim API, & GPS Geolocation.

Section 4

Key Features & Visual Highlights

📜 Interactive SVG North Indian Diamond Grid

Renders 12 House polygons dynamically in a 400x400 SVG viewBox. Houses show Rashi IDs (1-12), placed Graha symbols, combustion markers, and retrograde [R] flags. Clicking any house reveals Bhava details.

🏛️ 4 Divisional Varga Charts & Vargottama

Switch seamlessly between D1 (Rashi), D4 (Property), D9 (Navamsha), and D10 (Career) charts. Automatically checks `D1_Sign == D9_Sign` to display golden Vargottama badges.

⏳ Vimshottari Dasha & Parashari Yogas

120-Year recursive planetary timeline calculation based on elapsed Moon longitude fraction inside birth Nakshatra. Detects Gaja Kesari, Budhaditya, & Raja Yogas.

🔢 Numerology Suite & Viva Step Modals

Calculates Mulank, Bhagyank, and Chaldean Name Number. Universal '🧮 View Math' modals attached to every card display step-by-step formula arrays.
